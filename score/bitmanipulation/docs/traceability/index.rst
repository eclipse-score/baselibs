Lobster Traceability Report
############################

This page renders the Lobster traceability report generated by
``dependable_element_bitmanipulation``: feature and component requirements
linked to their GoogleTest unit tests, the architecture/public API, and the
safety analysis (failure modes, control measures and their FTA root causes).
The report is a plain build artifact read from disk; build it first with::

   bazel build //score/bitmanipulation:dependable_element_bitmanipulation

   bazel-bin/score/bitmanipulation/dependable_element_bitmanipulation_index_report.json
