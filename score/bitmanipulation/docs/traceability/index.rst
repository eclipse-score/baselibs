Lobster Traceability Report
############################

This page renders the Lobster traceability report generated by
``dependable_element_bitmanipulation`` (component requirements linked to their
GoogleTest unit tests). The report is a plain build artifact read from disk;
build it first with::

   bazel build //score/bitmanipulation:dependable_element_bitmanipulation
