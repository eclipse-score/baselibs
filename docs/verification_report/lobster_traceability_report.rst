Lobster Traceability Report
############################

This page renders the Lobster traceability report generated by
``dependable_element_baselibs``: feature and component requirements linked
to their GoogleTest unit tests, the architecture/public API, and the safety
analysis (failure modes, control measures and their FTA root causes).
Currently this only covers ``component_bitmanipulation``; as more baselibs
components are wired into ``dependable_element_baselibs`` (see //BUILD),
this report grows to cover them too.
The report is a plain build artifact read from disk; build it first with::

   bazel build //:dependable_element_baselibs

.. lobster-traceability-report::
   bazel-bin/dependable_element_baselibs_index_report.json
